# INTENTRA illustrative photography

These six website visuals were generated with the built-in image generation tool. They are illustrative scenes, not actual listings or verified locations. Existing INTENTRA logo assets were preserved.

- swiss.webp: Swiss alpine lakeside town, mountain peaks, blue lake and Swiss flag; cinematic travel photography, no text.
- auto.webp: silver sedan on a Swiss alpine road; no text.
- housing.webp: contemporary Swiss apartment building with glass balconies; no text.
- hotels.webp: illuminated alpine hotel at blue hour; no text.
- jobs.webp: construction professional in safety clothing, crane and Swiss alpine backdrop; no text.
- products.webp: shopping trolley with electronics and household products in a navy/cyan studio; no text.

Images are exported as optimized WebP for page loading performance. Category labels and interactive elements are HTML, translated into Romanian, German and English.
